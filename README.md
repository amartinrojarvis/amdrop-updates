# AMDrop · Actualizaciones

AMDrop abre el selector nativo de AirDrop al soltar archivos en su bandeja. Requiere macOS 14 o posterior.

- [Descargar AMDrop 0.1.5 para Apple Silicon e Intel](https://raw.githubusercontent.com/amartinrojarvis/amdrop-updates/main/0.1.5/AMDrop-0.1.5-universal.zip)
- [SHA-256](0.1.5/SHA256SUMS.txt) · [Catálogo firmado para Sparkle](appcast.xml)

Instala el ZIP una vez si tu versión no tenía canal. En adelante, haz clic secundario en el icono y usa **Actualizaciones → Buscar ahora…**. Sparkle comprueba las firmas Ed25519 del catálogo y del ZIP antes de instalar. El paquete no está notarizado por Apple; macOS puede pedir autorización para abrirlo o renovar permisos.

Este repositorio aloja solo archivos de distribución, no el código fuente.
